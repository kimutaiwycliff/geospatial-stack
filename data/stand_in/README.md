# Stand-in fixture (Phase 0 only)

`kenya_admin1_provinces.geojson` — 8 provincial boundaries for Kenya, extracted
from Natural Earth's 1:10m Admin-1 States/Provinces dataset
(`ne_10m_admin_1_states_provinces`, public domain / no attribution required:
https://www.naturalearthdata.com/about/terms-of-use/).

This is a disposable placeholder used only to prove the ingest → curate →
publish → tile → map pipeline end-to-end (build brief Phase 0, §0.4). It is
**not** LandMark data and carries none of LandMark's licensing/sensitivity
requirements — real LandMark datasets replace this in Phase 1 once data
access is granted (see `docs/data-loading.md`).
